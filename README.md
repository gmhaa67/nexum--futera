# Nexium Futura Academy

Premium online academy platform (frontend demo).

## How to run

1. Open the folder in **VS Code**
2. Open `index.html` with Live Server, or just double-click it in a browser

## Features

- **Login / Register** (Parent + Student details, stage, grade, country)
- **Student Dashboard** with sidebar navigation
- **Book a session** → Stages (KG → Secondary + Summer) → Grades → Subjects → Teachers
- **Free trial booking** + Zoom link + camera option
- **Country-based pricing** (Middle East currencies)
- **Admin panel** (full control)
